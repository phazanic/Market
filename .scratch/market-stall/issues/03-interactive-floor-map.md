# 03 — Field Collector: Interactive Market Floor Map

**What to build:** Mobile-responsive visual map displaying stalls by zone, color-coded by payment status, allowing the field collector to tap a stall and view its details.

**Blocked by:** 02 — Admin: Manage Master Data (Zones, Stalls, Vendors)

**Status:** ready-for-agent

- [ ] Field collector sees a mobile-friendly grid or map of stalls.
- [ ] User can filter the map to show only stalls in a specific Zone.
- [ ] Stalls are color-coded based on payment status (mocked or basic logic for now: Green=Paid, Red=Unpaid, Gray=Vacant).
- [ ] Tapping on a stall opens a slide-over drawer or modal showing stall details (number, rate) and current tenant info.
