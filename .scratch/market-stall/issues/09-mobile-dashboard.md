# 09 — Mobile-First Dashboard

**What to build:** The dashboard page is fully responsive and optimized for mobile screens (1-column stack), living inside the new unified shell rather than a separate admin layout.

**Blocked by:** 08-unified-mobile-shell

**Status:** ready-for-agent

- [ ] Dashboard metric cards (Revenue, Overdue, Occupancy) are stacked vertically in a single column on mobile screens.
- [ ] The Historical Statistics table is horizontally scrollable or reflowed to prevent breaking the mobile viewport width.
- [ ] The dashboard content is accessible via the "Dashboard" tab in the unified mobile shell.
