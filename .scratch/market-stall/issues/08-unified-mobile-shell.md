# 08 — Unified Mobile Shell Layout

**What to build:** A root-level Mobile Bottom Navigation bar (Map, Dashboard) so the user can easily switch between collecting rent and viewing stats on their phone without navigating back and forth.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] A sticky bottom navigation bar is visible on mobile devices.
- [ ] The navigation bar contains two main tabs: "Map" and "Dashboard".
- [ ] Tapping a tab smoothly switches the main content view between the Interactive Floor Map and the Dashboard.
- [ ] The active tab is visually highlighted.
