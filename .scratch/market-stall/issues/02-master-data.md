# 02 — Admin: Manage Master Data (Zones, Stalls, Vendors)

**What to build:** Admin dashboard screens to view, add, and edit Zones, Stalls, and Vendors (including fixed and casual tenants).

**Blocked by:** 01 — Database Schema & Project Setup

**Status:** ready-for-agent

- [ ] Admin can view a list of all Zones and add new ones.
- [ ] Admin can view a list of all Stalls, assign them to a Zone, set rates, and edit details.
- [ ] Admin can view a list of Vendors (tenants) and add new vendors with their contact info and type (fixed/casual).
- [ ] Forms include basic validation and save data correctly to the database via Server Actions.
